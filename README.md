# Himani Ingale | Portfolio Website

A personal portfolio website developed to explore creative frontend development, interactive animations, and modern web design.

🌐 **Live Website:** https://misshimaniingale.netlify.app/

## 🛠️ Tech Stack

- **HTML5** — Website structure and content
- **CSS3** — Styling, layouts, gradients, and visual effects
- **JavaScript** — Interactive functionality and dynamic behavior
- **GSAP** — Animation and motion effects
- **Vanta.js** — Animated background effects
- **Three.js** — Graphics support for visual effects
- **Git & GitHub** — Version control and source code management
- **Netlify** — Deployment and hosting

## 🎨 Design & Development

The website combines a modern visual style with interactive elements and animation to create an engaging browsing experience.

Key development approaches include:
- Custom CSS styling and gradient backgrounds
- Animated visual effects
- Interactive UI elements
- JavaScript-driven functionality
- Integration of animation and visual-effect libraries
- A focus on visual consistency and user interaction
